Overview

Built a full-stack desktop application for Trafikverket's R&D lab to solve a real problem: a growing archive of PDF documents that were hard to search and navigate. The app ingests PDFs, indexes them in a PostgreSQL database, and lets users find and query documents using a built-in AI chat powered by a locally-running LLM.

// The problem

Describe what the situation was before — too many documents, manual search, specific pain points the team had. What was the trigger for building this?

// Architecture

  • Frontend: Electron app with a web-based UI, running locally on Windows/Linux
  • Backend: Python (FastAPI or similar) handling scraping, PDF parsing, and LLM orchestration
  • Database: PostgreSQL storing document metadata, chunk embeddings, and search indices
  • AI: Ollama running a local LLM for RAG-style question answering — no data leaves the machine

// Key features

  • Automatic PDF scraping and ingestion from configured sources
  • Semantic search across the full document corpus
  • AI Q&A — ask questions in natural language, get answers with source citations
  • Fully offline / air-gapped — no external API calls, suitable for sensitive environments

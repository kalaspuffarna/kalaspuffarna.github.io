Overview

As part of Trafikverket's R&D lab, I designed and built a low-latency video distribution system running on a network of Raspberry Pi devices. The goal was to find a practical solution for distributing real-time video feeds with minimal end-to-end delay, suitable for infrastructure monitoring use cases.

// What I built

  • Evaluated and benchmarked multiple transport protocols (RTP/UDP, WebRTC, RTSP, SRT) for latency and reliability characteristics
  • Compared video codecs (H.264, H.265, AV1) under constrained network conditions
  • Implemented a Python-based distribution pipeline using GStreamer for encoding, transport, and decoding
  • Deployed and tested across a multi-node Raspberry Pi cluster
